# Mobility_Project

Este proyecto tiene como objetivo construir una tabla unificada que combine variables de movilidad urbana (fuente: TomTom) con variables económicas (fuente: OECD) para un conjunto de ciudades correspondientes al año 2024. La finalidad es generar una base de datos limpia, estandarizada y lista para análisis, que permita explorar en trabajos futuros la relación entre la movilidad urbana (congestión, tiempos de desplazamiento, velocidad promedio, entre otros indicadores) y la productividad económica a nivel de ciudad.

#	Etapa	Resultado esperado 🔬
1	Carga y exploración de ambos datasets	Identificación de columnas, tipos de dato y estructura general
2	Limpieza y corrección de formatos	Estandarización de nombres de columnas y corrección de tipos de dato
3	Extracción de año y filtrado a 2024	Subconjunto de datos correspondiente al período más reciente y relevante
4	Cálculo de promedios de tráfico por ciudad	Vista consolidada y agregada de movilidad urbana
5	Combinación de datasets (tráfico + economía)	Dataset unificado con una fila por ciudad, año 2024
6	Visualización de relaciones entre variables	Gráficos exploratorios sobre patrones entre tráfico y economía
7	Informe ejecutivo y reflexión final	Hallazgos, implicaciones de negocio y reflexión sobre la relación movilidad-economía

El entregable final consiste en un dataset consolidado y completamente depurado, junto con un Jupyter Notebook que documenta de forma reproducible todo el proceso: desde la carga e integración de ambas fuentes, pasando por la validación y limpieza de datos, hasta la exportación de la tabla final lista para su uso en análisis posteriores.
